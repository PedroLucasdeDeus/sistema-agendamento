# Clínica - Sistema de Agendamento

Sistema web para gerenciamento de clientes,
horários disponíveis e agendamentos de uma clínica.

## Tecnologias

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML
- CSS
- Jinja2

## Estrutura

O projeto utiliza Flask Blueprints para separar
os módulos da aplicação.

### Módulos

- Clientes
- Horários
- Agendamentos
